# Now or Never

Independent software studio by [echanxyz](https://0xechan.xyz).

Small tools, built fast, shipped now.

## Products

### macOS
- **[Markdown Now](https://md.nowornever.work)** — A fast, native macOS markdown editor built with Rust & GPUI. GPU-accelerated, vim mode, live preview.
- **[Porter](https://porter.nowornever.work)** — Dev servers, one click away. Lives in your menu bar, auto-discovers local servers.
- **[LB Liquidator](https://liquidator.nowornever.work)** — One-click position liquidation for Longbridge. Built with Tauri, local-only, open source.

### Chrome
- **[Form Snap](https://form-snap.nowornever.work)** — Stop re-filling forms. Chrome extension that replays form fills for faster QA. AI Fill for realistic test data.

### Web
- **[GEO Score](https://geo-score.nowornever.work)** — Is your website visible to AI search engines? Scan any URL and get a GEO readiness score. Free, no account required.

## Stack

- Next.js + Tailwind CSS + Geist fonts
- Deployed on Vercel
